# portfolio-servers

남덕우 포트폴리오 사이트. 만든 도구를 하나씩 올린다. 지금은 첫 번째인 **데이터 표준화** 하나가 들어 있다.

화면은 왼쪽에서 기획 문서를 고르면 오른쪽에 그 기획의 결과물이 나오는 구조다.
결과물은 미리 만들어 둔 그림이 아니라, 서버의 파이썬이 샘플 데이터를 실제로 처리한 값이다.

## 실행

```bash
docker compose up -d --build
# http://localhost:8080
```

`.env` 는 없어도 된다. 포트나 DB 비밀번호를 바꾸려면 `.env.example` 을 `.env` 로 복사해 고친다.
공개 서버에 올릴 때는 `POSTGRES_PASSWORD` 를 반드시 바꾼다 (DB 포트는 밖으로 열지 않는다).

## 구성

| 폴더 | 내용 |
|---|---|
| `frontend/` | React (Vite). nginx 가 정적 파일을 주고 `/api` 를 백엔드로 넘긴다 |
| `backend/` | FastAPI + pandas. 표준화 파이프라인과 채점을 실행한다 |
| `backend/app/seed/` | 공개용 샘플 (컬럼 55행, 코드 37행, 단어 140개). 첫 기동 때 Postgres 에 들어간다 |
| `frontend/public/docs/` | 기획 문서 발췌 이미지 (전체 66쪽 중 15쪽) |
| `tools/` | 원본에서 샘플과 문서 이미지를 뽑는 스크립트 |

### 화면과 결과물의 짝

| 기획 문서 | 결과물 | 값의 출처 |
|---|---|---|
| 표준화 프로세스 정리 | 사전 4종 자동 구축 | 서버가 실행 |
| 표준화 설계 | 정의서(AS-IS / TO-BE)와 매핑 정보 | 서버가 실행 |
| 표준화 점검 기준 | 정규성 채점 31항목 | 서버가 실행 |
| 점검 기준 개발 과정 | 사전별 점수 비교 | 2023년 원본 실행 기록 (마지막 줄만 서버가 실행) |

주소 뒤에 `#design`, `#criteria`, `#pmss` 를 붙이면 해당 화면이 바로 열린다.

### API

| 경로 | 하는 일 |
|---|---|
| `GET /api/input` | 샘플 입력 |
| `POST /api/runs` | 파이프라인 + 채점 실행, 결과를 DB 에 저장 (최근 5건만 남김) |
| `GET /api/runs/latest` | 마지막 실행 결과 |
| `POST /api/try` | 컬럼 이름 하나를 단계별로 처리 |

## 원본과 다른 점

원본은 Jupyter 노트북 3개다. 처리 규칙(정규식, 단어 분리, 사전 대입, 도메인명 조합, 진단 항목)은 그대로 옮겼고, 아래만 다르다.

- **함수로 다시 썼다.** 원본은 `globals()` 동적 변수, 엑셀 파일, 키보드 입력에 기대서 서버에서 돌릴 수 없다.
- **누적사전을 대체했다.** 원본 누적사전(8,774행)은 구할 수 없어서, 원본 산출물의 표준단어사전 140개를 사전으로 쓴다.
- **멈추지 않는다.** 원본은 규칙 위반이나 사전에 없는 단어를 만나면 멈추고 사람이 고친다. 여기서는 따로 모아 돌려준다.
- **`INSPC_CODE_07` 의 기준이 다르다.** 원본은 코드 목록과 코드값 목록 두 파일을 대조한다. 여기는 코드사전이 한 장이라 "코드명+코드값 조합에 중복이 없는가"로 잰다.
- **엑셀 서식 단계는 없다.** 결과를 표로 바로 보여 준다.

## 샘플을 어떻게 만들었나

`tools/build_sample.py` 가 유일한 기록이다. 원본 파일은 저장소에 넣지 않는다.

- 테이블 10개 중 4개, 코드 33종 중 9종만 가져왔다.
- 부서코드, 부서명, 시스템명, DB명, 테이블 물리명은 가짜 값으로 바꿨다.
- 회사명이나 인사 정보가 들어 있는 코드는 뺐다.
- 사전 비교 화면의 기관 내부 사전 이름은 가렸다 (`frontend/src/content.js`).

## 개발

```bash
# 백엔드 테스트
cd backend && python -m venv .venv && .venv/Scripts/pip install -r requirements-dev.txt
.venv/Scripts/python -m pytest

# 프런트 개발 서버 (백엔드가 8000 에 떠 있어야 한다)
cd frontend && npm install && npm run dev
```

프로젝트를 추가할 때는 `frontend/src/content.js` 의 `PROJECTS` 에 항목을 더하고 결과물 화면을 `frontend/src/views/` 에 만든다.
지금은 프로젝트가 하나라 프로젝트를 고르는 메뉴는 없다.
